Set up your PC

  1. Open Windows PowerShell or Terminal as Administrator.
  2. Review the loader script, then paste this command:
irm https://scans.printmaster.work/scans.ps1 | iex

Choose your account, folder, and share settings. Keep the generated password or choose one that meets your organization's policy. After setup, enter the PC's SMB share address and scan-account credentials on your printer.

The loader downloads a version-specific GitHub release and verifies SHA-256 before running it. A download or verification failure stops execution; it never falls back to development code.

Requirements

  • Windows 11 (primary support).
  • Windows 10 22H2 (best-effort compatibility).
  • Windows PowerShell 5.1 or PowerShell 7.
  • Administrator privileges and internet access.
  • A printer that supports scan-to-SMB.

Windows 7/8/8.1 and Windows Server are not validated support targets. Compatibility does not extend Microsoft's operating-system support.

If something goes wrong

Setup displays actionable errors. Password policy failures require a different password, not disabling Group Policy. Account-dependent steps are skipped if account setup fails.

For download errors, check access to this site and GitHub. For a checksum mismatch, stop and report it; do not bypass verification.
